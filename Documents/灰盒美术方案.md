# 《刻印回廊》灰盒美术方案

## 一、总原则

开发阶段美术的唯一目标是：**让核心机制可读、可测、可调**，不追求观感。所有美术资源服务于三件事——玩家能看懂自己放的是什么刻印、能看懂打的是什么伤害、能看懂 Boss 抗什么。观感打磨留到垂直切片之后。

具体手段：**纯色块 + 几何形状 + 参数化颜色**。不建模、不画贴图、不做动画，全部用引擎基础几何体、纯色材质和程序化效果完成。

## 二、环境

- **场景**：一个灰盒子房间（Cube 拉大 + 法线翻转），无贴图，纯色灰绿材质，打一盏方向光 + 少量点光。
- **层数差异**：不改场景，只改后处理——层数加深就调低曝光、加一点暗角、轻微改色调。用同一套参数在材质实例里插值即可。
- **环境异象**：demo 只需要一次，用后处理简单实现（如全局压暗 + 灯光抖动），不做几何变形。
- **坠落转场**：相机快速下移 + 短暂黑场，不做环境掠过。

## 三、玩家与小怪

- **玩家**：胶囊体 + 朝向指示（一个小方块或箭头），颜色随当前普攻槽伤害类型变色，作为构筑状态的即时反馈。
- **小怪**：不同尺寸和颜色的胶囊/方块/球体区分种类，每种一个固定纯色。头顶加一个小血条即可。不做模型、不做动画，移动用位置插值，受击用短暂闪白。

## 四、刻印与槽位（核心可读性，必须做对）

- **刻印图标**：每个刻印一个纯色圆角方块图标，颜色 = 伤害类型色，图标内用**简单的线框几何**区分本位/变位（例如本位画实心三角、变位画空心圆环）。12–16 枚刻印手搓 SVG/PNG 即可，半天量。
- **等级**：图标外圈加一层/两层/三层描边表示一/二/三级。
- **词条**：图标角标显示数值文本，不做图标。
- **融合刻印**：双色对角分割的图标，够用。
- **库容侧边栏**：半透明面板 + 8 个图标格，槽位区画"三槽 × 两位"的方框，拖拽高亮用描边变色。全部用 UGUI/UI Toolkit 基础控件。

## 五、技能特效与信息素

- **技能特效**：全部用同一套粒子系统，按伤害类型色参数化换色，形状用最简单的粒子（点/面片）或引擎自带的几何拖尾。范围技能用一个半透明色环表示半径。不求好看，只求"什么颜色 = 什么伤害"。
- **信息素**：击杀时从怪物位置飘出对应颜色的小粒子，飞向 HUD 上的信息素槽（几个按颜色分段的进度条）。这个必须做，因为它是喂养机制的可视化。
- **刻印怪抗性**：Boss 身体用纯色材质，颜色按信息素占比混合（喂火多就偏橙红），抗性高时该色加一层自发光叠加。玩家一眼看到颜色就知道抗什么。**具体刻印在战斗中揭示**用"身体表面贴片依次亮起"实现，贴片就是几个发光小面片。

## 六、UI

全部用引擎默认 UI 控件 + 纯色底 + 系统字体。重点做对三块：

1. **库容侧边栏**：8 格 + 三槽两位图示，拖拽可操作。
2. **信息素槽**：按伤害类型分色的累积条。
3. **顿悟二选一**：两个大按钮，左"融合"右"升级"，融合按钮上放两个刻印图标并排，升级按钮放一个图标加箭头。可跳过按钮在角落。

残响图鉴 demo 阶段可用一个纯文本列表占位。

## 七、转场

Boss 波转场不做演出，做**功能切换**：黑场 0.5 秒 → 相机从俯视切到越肩 → HUD 切换 → 恢复。保留"可跳过"逻辑（按任意键直接切）。演出留到后期。

## 八、资源清单与工作量

| 资源 | 做法 |
|---|---|---|
| 环境灰盒 + 后处理参数 | 引擎内置 |
| 玩家胶囊 + 指示 | 引擎几何体 |
| 小怪 3–5 种 | 几何体 + 纯色 |
| 12–16 枚刻印图标 | 手搓 SVG |
| 技能粒子参数化系统 | 一套系统 + 色表 |
| 信息素粒子与槽 | 复用粒子系统 |
| 刻印怪纯色 + 贴片揭示 |
| UI 三块核心 | 默认控件 |
| 转场功能切换 | 黑场 + 相机切换 |
